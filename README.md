# Marco.Dev Portfolio

## Files
- `index.html` — page structure/content
- `css/style.css` — stylesheet
- `js/script.js` — JavaScript
- `index-original.html` — backup of the original HTML

## Existing assets
Keep your existing `images/` and `CV/` folders in the same portfolio root. The HTML uses relative paths to those folders.

## VS Code
In VS Code choose **File → Open Folder...** and select this `Marco-Dev-VSCode` folder. Do not open the ZIP itself; extract it first.
